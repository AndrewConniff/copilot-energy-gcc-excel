# Excel Prompt Library

Classification: Public

This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## Primary prompt

`	ext
Analyze this worksheet, identify trends or anomalies, and suggest three questions I should ask the operations team.
`

## Follow-up prompts

`	ext
Turn the answer into three learner-friendly talking points and one caution about human review.
`

`	ext
Create a concise before-and-after explanation of how Copilot helps with this task without using web grounding or agents.
`

`	ext
List what I should verify before sharing this output with another person.
`

## Presenter note

If Copilot is not available in the GCC tenant, read these prompts aloud and show the expected workflow in the PPTX instead of attempting a live prompt.
